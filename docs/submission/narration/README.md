# Narration audio — Chirp3-HD (voice: Puck)

Generated by `scripts/narrate.py` using the project's own `media.speak()`, which
is the same Chirp3-HD synthesiser that reads statutory notices to families. The
demo is narrated by the voice the product ships.

**Total 3m 19s across ten sections**, measured with `afinfo`, against a 4:00 cap.
That leaves forty seconds of headroom, which is the point: the screen should be
allowed to breathe between sections rather than racing the audio. Run
`./scripts/narration_play.sh list` for the current per-section durations —
they are read off the files, so they cannot go stale.

`full-narration.mp3` is all ten joined, for a straight read.

**Playing it during an unedited take.** Play a section, let it finish, click to
the next screen, play the next. The judging criteria ask for a live unedited
demo — a voiceover is fine, splicing the screen recording is not. Section files
exist so you can pace the screen to the audio without ever cutting the video.

Regenerate with `.venv/bin/python scripts/narrate.py`. It caches by content
hash, so unchanged sections cost nothing.

**Changing the voice.** `narrate.py --voice Fenrir` re-renders in any of the
sixteen male Chirp3-HD en-US voices: Achird, Algenib, Algieba, Alnilam, Charon,
Enceladus, Fenrir, Iapetus, Orus, Puck, Rasalgethi, Sadachbia, Sadaltager,
Schedar, Umbriel, Zubenelgenubi. Puck and Fenrir read youngest; Charon and Orus
read older and more formal. The family-notice voice is unchanged — a letter read
to a parent and a demo read to a judge want different registers, so the narration
picks its own rather than inheriting the product default.
